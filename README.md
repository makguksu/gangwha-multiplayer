# 강화의 전장 - 친구와 실시간 대전

## 실행 방법 (VS Code / Node.js 있음 기준)

1. 이 폴더를 VS Code로 엽니다.
2. 터미널에서 의존성 설치:
   ```
   npm install
   ```
3. 서버 실행:
   ```
   npm start
   ```
4. 브라우저에서 `http://localhost:3000` 접속 → 방 코드 입력(예: ROOM1) 후 입장.
5. 친구도 같은 방 코드로 접속하면 자동으로 대전이 시작됩니다.

## 친구가 다른 컴퓨터/네트워크에 있을 때

- **같은 와이파이(집, 학교 등)에 있을 때**: 내 컴퓨터의 로컬 IP(예: 192.168.0.5)를 확인해서
  친구에게 `http://내IP:3000` 주소를 알려주면 됩니다.
  - Windows: `ipconfig` 로 IPv4 주소 확인
  - Mac: `ifconfig` 또는 시스템 설정 > 네트워크
- **완전히 다른 인터넷 환경(원격)일 때**: 포트포워딩이 번거로우니 아래 중 하나를 추천합니다.
  - `ngrok` 사용: `npx ngrok http 3000` 실행 후 나오는 https 주소를 친구에게 전달 (제일 간단)
  - Render.com, Railway.app 같은 무료 호스팅에 이 폴더를 그대로 배포 (Node.js 프로젝트로 인식됨)

## 게임 규칙 요약

- 체력 100, 손패 최대 7장(공격 1~14 / 방어 1~14 / 회복 1~20 랜덤 생성)
- 방어카드는 사용해도 소모되지 않고 계속 재사용 가능
- 강화카드(예: "3~7")를 공격카드와 함께 내면 그 범위에서 랜덤 보너스 데미지가 추가됨
- 서버가 모든 판정(랜덤값, 데미지 계산, 턴 순서)을 갖고 있어 클라이언트 조작이 불가능함
- 상대 체력이 0이 되면 승리/패배 화면 표시

## 구조

```
gangwha-multiplayer/
├── package.json
├── server.js        # 게임 상태를 갖고 있는 서버 (Express + Socket.io)
└── public/
    └── index.html   # 방 참가 화면 + 대전 화면 (클라이언트)
```

밸런스(체력, 카드 범위, 손패 수 등)를 바꾸고 싶으면 `server.js` 상단의
`MAX_HP`, `HAND_SIZE`, `makeCard()` 함수 안의 숫자 범위만 수정하면 됩니다.
